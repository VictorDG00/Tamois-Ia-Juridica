Fluxo 5 — Chat Jurídico

Assistente conversacional ativado após a análise ser concluída. O usuário faz perguntas sobre o documento e recebe respostas contextualizadas. Fluxo independente — não faz parte do pipeline de análise dos fluxos 1–4.

Chat vs. Pipeline de Análise DIFERENÇAS

Pipeline (fluxos 1–4)

Temperatura 0.1 — determinístico
Output obrigatório em JSON
Texto limitado a 20.000 chars
Sem histórico — chamada isolada
Roda uma vez, durante o processamento
Output salvo no banco de dados

Chat (fluxo 5)

Temperatura 0.5 — conversacional
Output em texto livre / Markdown
Texto até 160.000 chars
Histórico das últimas 10 mensagens
Roda a cada mensagem do usuário
Output exibido em tempo real na UI
O que o Chat sabe sobre a análise CONTEXTO
  • ✅ Quantidade de itens: quantas correções, sugestões e insights foram encontrados, e quantos são de alto risco.
  • ✅ Texto do documento: o documento completo (até 160.000 chars) está no system message — o modelo pode citar trechos exatos.
  • 🚫 Detalhes dos itens: o chat não recebe o JSON das análises — não sabe quais erros específicos foram encontrados, só a quantidade total. O usuário pode perguntar sobre o documento, não sobre "o que o sistema encontrou".
⚠️ Oportunidade de melhoria: incluir o JSON resumido das análises no system message permitiria ao chat responder perguntas como "me explique o risco de alto nível que você encontrou". Hoje isso não está implementado.
Dicas para Testar e Iterar TESTE
  • 1️⃣ Teste perguntas sobre o documento ("O que diz a cláusula de multa?") — o modelo deve responder citando o texto.
  • 2️⃣ Teste perguntas fora do escopo jurídico — o modelo deve se manter no papel de assistente jurídico e recusar ou redirecionar.
  • 3️⃣ Teste a coerência de histórico: faça uma pergunta, receba resposta, faça uma pergunta de acompanhamento — o modelo deve lembrar o contexto.
  • 4️⃣ Verifique o tom: deve ser objetivo e profissional, não excessivamente formal ao ponto de ser ilegível.
✅ Critério de aprovação: respostas ancoradas no texto do documento + tom profissional-acessível + coerência de histórico + limites claros de escopo.
